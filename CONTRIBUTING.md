# Contributing to ISORYN

ISORYN is in governed bootstrap and architecture discovery.

Before changes, read AGENTS.md, .engineering/SOURCE-HIERARCHY.md and the canonical checkpoint. All accepted work must bind to a Work Order, exact Git base/head, required evidence and an audit verdict.

The one-time empty-repository bootstrap may land directly on main. After bootstrap, normal work uses work/<work-order-id>-<slug> branches and pull requests.

Use Conventional Commits. Do not force-push, rewrite history, weaken tests/security/evidence gates or promote checkpoint truth without authorization.
