# Contributing to ISORYN

ISORYN is in governed bootstrap and architecture discovery. Read AGENTS.md, .engineering/SOURCE-HIERARCHY.md and the canonical checkpoint before changes.

The one-time empty-repository bootstrap may land directly on main. After bootstrap, normal work uses work/<work-order-id>-<slug> branches and pull requests. Use Conventional Commits. Do not force-push, rewrite history, weaken tests/security/evidence gates or promote checkpoint truth without authorization.
