# Contributing to ISORYN

ISORYN is in governed bootstrap and architecture discovery. Read AGENTS.md, .engineering/SOURCE-HIERARCHY.md and the canonical checkpoint before changes.

The one-time empty-repository bootstrap landed directly on main before any branch protection existed. Since the
`main-governance` ruleset is active, all later work uses branches and pull requests. The default branch pattern is
`work/<work-order-id>-<slug>`; when a Work Order designates an exact branch name, that name overrides the default and
is recorded in the Work Order. Use Conventional Commits. Do not force-push, rewrite history, weaken
tests/security/evidence gates or promote checkpoint truth without authorization.
