# ISORYN GEF Policy

1. Canonical source truth outranks chat memory and derived caches.
2. Product work requires an admitted Work Order.
3. Every Work Order binds execution base and evidence.
4. Context locks become stale when material authority/base changes.
5. Deterministic proof precedes LLM inference when practical.
6. HIGH/CRITICAL known defects block promotion.
7. Evidence binds the exact candidate/head.
8. Checkpoint promotion follows audit.
9. Scope discoveries are NECESSARY, IMPORTANT, FUTURE or OUT OF SCOPE before admission.
10. Destructive Git/history operations require explicit authorization.
11. Reviewer-first correction applies when safe and exactly validatable.

HIVE is preferred intelligence, not canonical-write authority.
