# ISORYN Project Overview

## Mission
Build ISORYN as a high-performance, high-fidelity, AI-native game engine program using Godot 4.x as the foundation direction while integrating HIVE, CORE and IRIS through explicit contracts.

## Product intent
Target demanding 2.5D/3D and isometric game production with measurable improvements in rendering, lighting, streaming, materials, geometry, animation, physics, world simulation, tooling, asset pipelines, hardware adaptation, profiling and AI-assisted production.

ISORYN is not a cosmetic Godot wrapper. Prefer extensions/modules and upstream compatibility where practical; own deeper forks/replacements only when benchmarked value justifies maintenance cost.

Current stage: repository bootstrap and architecture discovery. No engine implementation is authorized yet.
