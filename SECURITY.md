# Security Policy

ISORYN is pre-release. Never commit credentials, private keys, tokens, local secrets or production data. Treat plugins, native extensions, Godot add-ons, shaders, imported assets, archives, DCC files, models, prompts, MCP content and external binaries as untrusted until validated.

HIGH or CRITICAL security findings block promotion. Supply-chain, plugin, scripting, asset-import and native-extension boundaries require explicit threat analysis before production use.
