# Security Policy

ISORYN is pre-release. Do not report secrets or sensitive exploit material in public issues.

Never commit credentials, private keys, tokens, local machine secrets or production data. Treat external assets, plugins, Godot add-ons, DCC files, models, prompts, MCP inputs and downloaded binaries as untrusted until validated.

Security findings rated HIGH or CRITICAL block promotion. Supply-chain, plugin, scripting, asset-import and native-extension boundaries require explicit threat analysis before production use.
